# Project history

The repository log records the milestones represented by the source material available for this project:

1. Initial synthetic intake LoRA experiment.
2. ConstructCIE and OSHA classification experiments.
3. v2.1 evaluation and audit tooling.
4. Repository consolidation, documentation, and follow-up corrections.

The log documents changes in this repository; author and timestamp metadata should not be treated as independent evidence of when the underlying experiments were performed. The methodology and results documents describe the available experiment provenance and its limitations.
